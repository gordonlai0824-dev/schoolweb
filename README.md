# 中華基督教會灣仔堂基道小學（九龍城）— 學校網站及後台

以家長需要為本的新版學校網站，並附有**網站後台**，老師登入後可自行新增、修改、隱藏或刪除內容，毋須編寫程式。

- 前台：首頁 + 七個家長導向主選單（認識基道／發展新里程／學與教／學生成長／成果與故事／家長專區／學校資訊）+ 英文版重點頁
- 後台：`/admin`（消息、獎項、校曆、通告、常見問題、心聲、內頁內容、網站設定、帳戶管理、資料檢查）
- 技術：Python 3.10+、Flask、SQLite（單一資料庫檔案，毋須另裝資料庫伺服器）

## 一、如何對應改版建議

| 建議 | 網站實現方式 |
|---|---|
| 首頁資訊有優先次序 | 首頁依次為：發展計劃橫幅 → 快捷入口 → 校長的話 → 兩項三年重點及路線圖 → 為何選擇基道 → 學校動態 → 精選成果 → 校曆及心聲 → 小一入學 |
| 校長及發展計劃要突出 | 橫幅主標題及兩項關注事項置於首頁最顯眼位置；校長引言、短片按鈕、每月「校長短訊」 |
| 獎項由「名單」變「成果故事」 | 首頁只顯示「精選成果」（附成果故事）；完整名單移至「成果與故事 › 學生成就」，可按範疇及學年篩選 |
| 比賽年份顯示 2027–2036 等錯誤 | 後台輸入獎項時，**日期必須在所選學年內**，年份不合理會被拒絕；「資料檢查」頁自動列出可疑日期 |
| 資訊分流（參考保良局何壽南小學） | 首頁「最新消息／學生喜訊／校園活動」分頁顯示，每則只顯示圖片、短標題及日期 |
| 家長導向選單（參考聖公會聖十架小學） | 七個一級選單完全按建議命名；學生成就分「學術與創科／體藝／服務與領袖」 |
| 家長最常查閱（參考聖公會聖提摩太小學） | 每頁頂部「家長最常查閱」列：校曆、通告及表格、小一入學、午膳及校車、聯絡我們 |
| 家長／學生心聲、校友故事 | 「家長及學生心聲」可於後台管理，首頁及校友頁自動顯示 |
| 活動呈現目標、過程、成果及反思 | 編輯器設有「+成果四格」一鍵插入「目標・過程・成果・反思」版面 |
| 中英文雙語重點內容 | `/en` 英文重點頁（內容可於後台「內頁內容」修改） |
| 手機版及無障礙 | 手機優先版面、字體大小切換（A／A+／A++）、鍵盤操作、跳至內容連結、替代文字提示 |
| 定期檢查失效連結及錯誤日期 | 後台「資料檢查」自動核對：日期與學年、未來日期、重複資料、待填寫內容、內部失效連結、未上載的文件 |

## 二、老師使用後台（日常更新）

1. 進入 `https://（學校網址）/admin`，以帳戶登入（網站頁尾亦有「教職員登入」連結）。
2. 主控台「快速新增」提供最常用的工作：

| 工作 | 位置 | 小貼士 |
|---|---|---|
| 最新消息、學生喜訊、校園活動、校園故事、學生作品、傳媒報導、校長短訊 | 消息及故事 | 選擇「類別」即決定顯示位置；勾選「首頁精選」可放到首頁「成果與故事」 |
| 學生獎項 | 學生成就 | 只寫班別及姓氏（例：5A 陳同學）；精選成果建議附一兩句「成果故事」 |
| 一次輸入大量獎項 | 學生成就 › 大量匯入 | 由 Excel 複製「日期、範疇、比賽名稱、獎項、得獎學生」五欄直接貼上，系統先檢查再匯入 |
| 校曆 | 校曆 | 多日活動填「結束日期」；過期事項首頁會自動隱藏 |
| 家長通告、表格、學校報告 | 通告及文件 | 上載 PDF；或填寫外部連結（例如教育局報告） |
| 內頁文字（例如小一入學、課程特色） | 內頁內容 | 新增區塊會**自動加入主選單**的下拉清單 |
| 首頁橫幅、校長的話、發展計劃階段、聯絡資料 | 網站設定（管理員） | 每學期更新「目前階段」，首頁路線圖會自動更新 |

**編輯器功能**：標題、粗體、清單、連結、插入相片（亦可直接貼上截圖）、YouTube 影片、重點框、卡片、剔號清單、成果四格、表格；由 Word 貼上會自動清除多餘格式。

**隱藏 vs 刪除**：取消勾選「公開顯示」只會暫時隱藏，日後可再公開；刪除則無法復原。

**帳戶權限**：
- 編輯（一般老師）：更新所有內容
- 管理員：另可管理帳戶、主選單頁面、網站設定及查看修改紀錄

所有新增、修改及刪除均記錄於「修改紀錄」。

## 三、安裝及啟動（IT 同工）

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt
```

```bash
.venv/bin/python run.py
```

開啟 http://127.0.0.1:8000 。首次啟動會自動建立資料庫及示範內容，並在終端機顯示管理員帳戶 `admin` 的隨機密碼（亦可預先設定環境變數 `KT_ADMIN_PASSWORD`）。

Windows 請以 `.venv\Scripts\python run.py` 執行。

### 正式環境

```bash
KT_HOST=0.0.0.0 KT_PORT=8000 KT_SECURE_COOKIES=1 .venv/bin/python run.py --prod
```

- 使用 Waitress（支援 Windows 及 Linux），建議前置 Nginx／IIS 反向代理並啟用 HTTPS。
- `KT_SECURE_COOKIES=1` 只在 HTTPS 下使用。
- 上載檔案上限 25MB。

### 備份

所有資料存放於 `instance/` 資料夾：

- `instance/site.db`：網站內容及帳戶
- `instance/uploads/`：上載的相片及文件
- `instance/secret_key`：登入加密金鑰

**請定期備份整個 `instance/` 資料夾。** 更新程式時不會影響此資料夾。

### 指令

```bash
.venv/bin/flask --app run create-user chan_tm --name 陳老師
```

```bash
.venv/bin/flask --app run reset-password admin
```

### 環境變數

| 變數 | 用途 |
|---|---|
| `KT_ADMIN_PASSWORD` | 首次建立資料庫時的管理員密碼 |
| `KT_SECRET_KEY` | 登入加密金鑰（不設定則自動產生於 `instance/secret_key`） |
| `KT_INSTANCE` | 資料夾位置（預設 `instance/`） |
| `KT_HOST`／`KT_PORT` | 伺服器位址及埠號 |
| `KT_SECURE_COOKIES` | 設為 `1` 時登入 Cookie 只經 HTTPS 傳送 |

### 測試

```bash
.venv/bin/python -m unittest discover -s tests
```

## 四、正式發佈前必須核實或替換的內容

網站頂部的黃色提示列會顯示「網站設計原型」字樣，完成以下工作後，可於「網站設定 › 網站設定」把「顯示頂部提示列」改為 `0`。後台「資料檢查」會列出大部分待處理項目。

1. **聯絡資料**：電話、傳真、電郵、辦公時間（目前為「請於後台填寫」）。地址「九龍九龍城靠背壟道170號」取自教育局校外評核報告，請再核對。
2. **校長姓名、近照及短片**；首頁及校長的話全文（目前按 2026–2027 校長的話方向撰寫）。
3. **校徽**：以學校正式校徽替換 `kt/static/img/logo.svg`。
4. **相片**：網站以色塊代替相片，請在各消息上載封面相片；內頁的「相片：…」色塊可在編輯器中刪除並插入真實相片。
5. **示範內容**：所有標示「示範」的消息、獎項、心聲及首頁數字均為版面示範，請替換或刪除。
6. **校訓、學校歷史年份、校園設施、課外活動、BYOD 安排**：請按實際情況更新。
7. **傳媒報導日期**：四篇星島報導的連結為真實報導，但日期需核實。
8. **文件**：上載學校發展計劃、周年計劃、學校報告、通告及表格的 PDF。

## 五、檔案結構

```
run.py                 啟動程式
kt/__init__.py         網站設定、首次建立資料庫
kt/public.py           前台頁面
kt/admin.py            後台（內容類型、欄位、驗證、資料檢查）
kt/seed.py             初始內容（只在首次建立資料庫時使用）
kt/content.py          類別選項（消息類別、獎項範疇等）
kt/sanitize.py         清理編輯器內容，防止惡意程式碼
kt/templates/          前台及後台版面
kt/static/             樣式、程式、校徽
tests/                 自動測試
instance/              資料庫及上載檔案（不納入版本控制，須備份）
```

## 六、持續更新建議（第三階段）

- 每月一篇「校長短訊」（消息及故事 › 類別：校長短訊）
- 每兩週一篇「校園故事」（使用「+成果四格」記錄目標、過程、成果及學生反思）
- 每學期更新「網站設定 › 三年發展計劃 › 目前階段」及路線圖文字
- 每月查看一次「資料檢查」
